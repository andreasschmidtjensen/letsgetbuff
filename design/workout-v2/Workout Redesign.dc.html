TURN 1 · LET'S GET BUFF

Training together on one phone

Three takes on the focus screen — 1a, 1b, 1c — each with a different answer to the two-person rest problem. Below them: the Side Plank / per-side fix (1d), overview and today (1e), and the e-ink check (1f). New type: Sora for UI, JetBrains Mono for every number. Amber stays you, lime is your partner, and "done" is a plain tick so colour never carries two meanings.

1a Rest dock

Rest never covers the screen. Two lanes live in a dock above the nav — one per person, each with its own countdown. In rest together the lanes merge into one wide lane. Confirming a set starts only your lane; the partner's lane keeps running so you can always see who is up next. You can log, fix a number or watch the video while resting.

1b Split ring

Rest keeps the full-screen ring you have today, but the ring is split in two arcs — amber outside for you, lime inside for her. Whoever hits zero first gets the whole screen: a big "GO" and the name. Readable from a metre away with the phone on the floor. In together mode the two arcs fuse into one thick ring.

1c Relay rows

No overlay at all. The exercise is two equal rows and each row is a state machine: ready → logging → resting. Whoever is ready expands and shows the inputs; the other row collapses to a countdown. Turn-taking is the layout, so a session on one phone reads like a relay — and either person can log without hunting for a proxy toggle.

1d Per-side sets, and re-opening a rep

Applies to whichever layout you pick. A /side set is one set with two holds: left, a hand-over step, then right. The set only ticks when both sides are logged, and a finished set always keeps a restart button, so re-opening never leaves you without a timer.
